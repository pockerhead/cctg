# TASK-033: notify when a subagent finishes

Type: feature
Mode: small-fix
Priority: medium
Branch: feature/subagent-done-reply
Domains: hub

## Description
Пользователь (2026-09-24): блок субагента (TASK-015) по окончании молча редактируется на итог, и в Telegram это не видно как событие (правка не даёт уведомления). Нужно: когда блок субагента или вложенного запуска переходит в итог (или «итог не получен»), hub отправляет короткое отдельное сообщение ответом (`reply_to_message_id`) на сообщение блока: `✓ <тип> <short id> закончил` (или `✗ … итог не получен`), чтобы пришло уведомление и по нажатию было видно блок. Один раз на блок, через планировщик (metered), не при рестарте hub для уже законченных блоков, не для блоков без `message_id` (tombstone). Для документа длинного итога ничего дополнительно не нужно.

## Acceptance criteria
- [ ] завершение субагента даёт одно сообщение-ответ на его блок; вложенный запуск тоже
- [ ] повторная правка того же блока или рестарт hub второго сообщения не дают
- [ ] блок без message_id не даёт ответа
- [ ] Existing tests pass
