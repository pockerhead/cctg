# TASK-039: end sessions whose claude process died without SessionEnd

Type: fix
Mode: small-fix
Priority: high
Branch: fix/dead-session-reconcile
Domains: hub, hooks

## Description
Живой баг 2026-09-24: сессия, у которой процесс claude умер без хука `SessionEnd` (окно закрыли, `taskkill /F`, падение), навсегда числится живой в реестре hub (`ended: false`, её `claude_pid` уже не существует). Следующая сессия в той же папке получает `#2` вместо освободившейся темы (так появились `VOIDRUN #2` и `Git #2`). Нужно:
1. Хук `SessionStart` (он уже обходит дерево процессов для вложенности, `proctree.rs`) добавляет в событие список pid живых процессов claude на этой машине (optional поле, wire без VERSION bump). Hub до выбора слота помечает ended все незавершённые сессии этого host, чьи `claude_pid` не в списке (включая nested), с обычными последствиями SessionEnd (тема dead, буфер TASK-017, блоки TASK-015, стрим). Проверить, что host совпадает и что сессии без `claude_pid` не трогаются.
2. Агент-линк: если сессия имела агента и тот отключился и не вернулся за 60 с, hub спрашивает об этом при следующем событии этого host (или по таймеру ничего не делает сам — только отмечает кандидата; решение по списку pid из п.1 или из следующего хука любого события этого host, если он несёт список). Минимальный вариант: список pid шлёт каждый SessionStart и SessionEnd хука; этого достаточно для ротации слотов. Решить и обосновать.
3. Hub при старте ничего не угадывает (устройства могут быть удалёнными); сверка только по свежим данным с того же host.
