# PCTX proposals (TASK-044, planner)

- 2026-09-26, домен channel, Risk lessons: на macOS нативный Claude Code запускается как `~/.local/share/claude/versions/<версия>` через ссылку `~/.local/bin/claude`, и имя процесса (`pbi_comm`/`pbi_name`, `proc_pidpath`, Activity Monitor) это номер версии, а не `claude` (anthropics/claude-code#12433). Любая проверка «это claude» по имени процесса на macOS должна смотреть и на путь образа (`.../claude/versions/<x>`). Основание: TASK-044, `proctree::process_name`.
- 2026-09-26, universal или channel: псевдотерминал нельзя переиспользовать для следующего процесса после выхода лидера сессии: XNU отзывает (revoke) управляющий терминал при выходе лидера, Linux для pty этого не делает. Обёртки вроде `cctg run` открывают новый pty на каждый запуск claude. Основание: TASK-044, `term::Host::command`.
- 2026-09-26, universal: процесс в собственном pty (`setsid` + `TIOCSCTTY`) это осиротевшая группа процессов, и ядро выбрасывает для неё SIGTSTP/SIGTTIN/SIGTTOU с действием по умолчанию. Для «приостановить вместе с потомком» использовать SIGSTOP (Claude Code сам останавливается SIGSTOP, стек в anthropics/claude-code#4035). Основание: TASK-044, `term::Host::wait`.
- 2026-09-26, universal (повтор кандидата из TASK-035): Bash-инструмент ломает heredoc, в котором есть `\` + перевод строки (и Python-строки с `\u`): такие правки писать через Write/Edit или скрипт-файл, а не через heredoc в Bash.

- 2026-09-26, universal (reviewer 2): Unix-only code (cfg(unix), libc, pty, proc_*) can be type-checked and clippy-linted on the Windows host without installed targets: a mini crate with the real files plus stubs, `RUSTC_BOOTSTRAP=1 cargo clippy -Zbuild-std=std,panic_unwind --target x86_64-unknown-linux-gnu|x86_64-unknown-linux-musl|aarch64-apple-darwin -- -D warnings` (rust-src is installed; the whole cctg crate cannot, aws-lc-sys needs a C cross toolchain). It caught 3 CI breakers in TASK-044 that `rustfmt` and a manual libc signature check missed (an unresolved `common::` path inside a nested test module, `clippy::unnecessary_mut_passed` for `&mut` into Linux `*const` params: pass `&raw mut x`). Script: `maw/tasks/in_progress/TASK-044/scratch/reviewer2/unixcheck/unixcheck.sh`.
