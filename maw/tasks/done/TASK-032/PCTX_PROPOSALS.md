По докам Claude Code (https://code.claude.com/docs/en/mcp, «Dynamic tool updates») список перечитывается; живьём не проверено.
4. **CLAUDE.md, «Telegram Bot API» (факты из документации и исходников, не живой прогон).** Бот скачивает файлы до 20 MiB (`MAX_DOWNLOAD_FILE_SIZE = 20 << 20` в telegram-bot-api `Client.h`; больше — `400 Bad Request: file is too big`), ссылка `getFile` живёт не меньше часа, `file_id` постоянный. Загрузка multipart: фото до 10 MB (`width + height ≤ 10000`, соотношение ≤ 20), прочее до 50 MB. `animation` приходит вместе с `document`, `live_photo` вместе с `photo`; `photo` это массив размеров. Подпись 0–1024 символа.
