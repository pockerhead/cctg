# TASK-032: files both ways between the topic and the session

Type: feature
Mode: full
Priority: high
Branch: feature/files
Domains: hub, channel

## Description
Пользователь хочет кидать файлы (документы, фото, скриншоты) в тему сессии и получать файлы от агента обратно.
- Из темы в сессию: hub принимает `document`/`photo` (самый большой размер)/`video`/`voice` от allowlisted-пользователя, скачивает через `getFile` (лимит Bot API 20 MB; больше — понятный ответ в теме), передаёт байты агенту сессии по agent-линку (новое сообщение за capability в Register, чанками в пределах `wire::MAX_LINE`, без VERSION bump), агент сохраняет файл на машине сессии (например `<session cwd>/.cctg/inbox/<дата>-<имя>` или временная папка; решить и обосновать; имя санитизировать, без перезаписи) и шлёт в Claude Code channel-сообщение с путём, подписью и типом. Для мёртвого слота файл ждёт в буфере (TASK-017) как ссылка на `file_id`, не байтами. Текущая заглушка "только текст" для таких сообщений уходит.
- Из сессии в тему: новый MCP-инструмент канала `send_file(path, caption?)`: агент проверяет путь (обычный файл, размер ≤ 50 MB), читает и отдаёт hub, hub шлёт `sendPhoto` для картинок и `sendDocument` для остального в тему слота через планировщик. Инструкции канала описывают, когда им пользоваться.
- Файлы идут через агента, а не через диск hub, чтобы работало с удалённым hub.
- Секреты, содержимое файлов и имена файлов пользователя в логи не пишутся (только размеры и типы).

## Acceptance criteria
- [ ] документ и фото из темы оказываются файлами на машине сессии, сессия получает путь и подпись; >20 MB даёт понятный ответ
- [ ] `send_file` отправляет картинку как фото и прочее документом в тему своей сессии; путь вне файла или >50 MB даёт ошибку инструмента
- [ ] передача по agent-линку чанками, старый агент без capability получает понятную заглушку, VERSION не меняется
- [ ] мёртвый слот буферизует файл ссылкой и доставляет при оживлении
- [ ] тесты через настоящий `serve_agents` и фейковый Bot API; содержимое и имена файлов не в логах
- [ ] Existing tests pass
