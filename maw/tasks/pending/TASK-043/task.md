# TASK-043: bang and slash commands from the topic go to the session console

Type: feature
Mode: small-fix
Priority: medium
Branch: feature/console-commands
Domains: hub, channel

## Description
Решение пользователя 2026-09-24: сообщение в теме, начинающееся с `!` (нативный bash-режим Claude Code) или со слэш-команды, которую hub сам не обслуживает (`/compact`, `/model`, `/clear`, `/cost` и т.д.; свои `/brief`, `/full` и прочие hub оставляет себе), не уходит модели текстом, а набирается в консоли claude этой сессии, как если бы пользователь набрал его в терминале. Механизм: агент (TASK-029 `keys.rs`, WriteConsoleInputW в консоль своего claude) с той же проверкой поля ввода, что безопасный `/exit` из TASK-040 (набрать, прочитать строку ввода с экрана с нормализацией U+00A0, Enter только если там ровно набранное, иначе стереть набранное и отказать). Если идёт ход, команда не набирается: ответ в теме «сессия занята, повтори после хода» (или очередь до конца хода — решить и обосновать). Только allowlisted, только живая сессия с агентом, поддерживающим capability; иначе понятный ответ. Длина и символы команды ограничены (одна строка, без управляющих символов). Результат виден через обычный стрим (вывод `!` попадает в транскрипт как bash-input/bash-stdout — проверить формат и отрисовать строкой) и закреп.

## Dependencies
- blocked by TASK-040 — shares the safe console typing

- [ ] при черновике в поле ввода или идущем ходе команда не набирается, пользователь получает понятный ответ
- [ ] только allowlisted, многострочные и управляющие символы отклоняются
- [ ] Existing tests pass
