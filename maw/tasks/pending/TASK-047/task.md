# TASK-047: no restart while background agents run or an agent view is open

Type: bugfix
Mode: small-fix
Priority: high
Branch: fix/restart-guard
Domains: channel

## Description
Найдено вживую 2026-09-25 (сессия test-gta-like): «Обновить» дошло до перезапуска, агент набрал `/exit`, но в терминале был открыт вид субагента (поле ввода «Message @maw-qa-medium…», внизу список агентов, `maw-qa-medium` работал 35 минут). Поле ввода не распозналось, набранное стёрлось, в тему ушло «Обновить клиент не получилось». Если бы `/exit` прошёл, он убил бы работающих фоновых агентов, хотя hub считал сессию свободной (основной ход закончен).

Перед `/exit` (и перед любой набираемой командой TASK-043) агент читает экран: если открыт вид субагента (плейсхолдер `Message @…` или выбран не `main` в списке агентов) или в списке агентов есть работающий (строка агента с `●`/таймером), команда не набирается. Для перезапуска: ответ `busy`-подобный исход, hub пишет в тему один раз «перезапуск ждёт, пока закончат фоновые агенты» и повторяет, как при идущем ходе (UPDATE_WAIT/раунды). Для команд из темы: понятный отказ. Фикстуры экрана из этого случая (без содержимого пользователя) в тестах.

Дополнение пользователя 2026-09-25: если перезапуск всё же прервал работу (пользователь нажал ⏹ или «прервать и обновить», или ход шёл в момент `/exit`), hub запоминает это и после того, как агент перезапущенной сессии привязался, отправляет в сессию обычное inbound-сообщение канала: «Клиент cctg обновлён, сессия перезапущена посреди работы; продолжи с того места, где остановился» (если были работающие фоновые агенты, добавить, что их нужно запустить заново). Без прерванной работы (обычный перезапуск в простое, замена воркера без перезапуска) сообщение не отправляется.

## Acceptance criteria
- [ ] экран с видом субагента или работающим фоновым агентом: `/exit` не набирается, в тему понятное сообщение, повтор после окончания
- [ ] обычный экран: поведение прежнее
- [ ] перезапуск, прервавший ход, даёт одно сообщение-продолжение в сессию после привязки нового агента; перезапуск в простое не даёт (тест через фейковый линк)
