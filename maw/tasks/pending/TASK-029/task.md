# TASK-029: pinned status message with an interrupt button

Type: feature
Mode: full
Priority: medium
Branch: feature/status-interrupt
Domains: hub, channel

## Description
Пользователь хочет в каждой теме закреплённое сообщение со статусом сессии (думает / выполняет инструмент / ждёт разрешения / ждёт пользователя / сессия завершена) и кнопку ⏹ «Прервать», которая останавливает текущий ход как Esc в терминале. Статус берётся из существующих сигналов (UserPromptSubmit, стрим, permission prompts, Stop, SessionEnd); сообщение одно на слот, редактируется, закрепляется один раз (служебное сообщение о закреплении удаляется, как forum_topic_edited). Прерывание: у каналов нет официальной команды; предполагаемый путь на Windows — `cctg agent` (дочерний процесс claude) делает AttachConsole к консоли своего claude и пишет Esc через WriteConsoleInputW. Сначала проба (скрытая консоль, по правилу README), подтверждающая, что Esc так останавливает ход; если нет — найти другой путь или честно отказаться. Кнопка только для allowlisted, с подтверждением от случайного нажатия.

Дополнение пользователя (2026-09-24): статус показывать эмодзи, а цифрами показывать текущий контекст и лимиты, как в его statusline (`~/.claude/statusline.py`: модель, effort, `ctx:NN%`, `5h:NN%`, `7d:NN%`). Источник цифр: Claude Code сам отдаёт statusline-команде JSON с `session_id`, `model`, `context_window.used_percentage`, `rate_limits.five_hour/seven_day.used_percentage`. Предлагаемый путь: в `--settings` cctg-сессий переопределить `statusLine` на `cctg statusline --chain <команда пользователя>`: она шлёт эти поля в hub (коротко, без блокировки, с троттлингом) и печатает вывод команды пользователя, чтобы терминал выглядел как раньше. Работать должно на любой машине, не только у этого пользователя: `cctg statusline` сам на каждом вызове читает `statusLine.command` из пользовательского `~/.claude/settings.json` (или `CLAUDE_CONFIG_DIR`) и запускает его с тем же stdin, а если его нет, печатает собственную короткую строку (модель, ctx, 5h, 7d); цифры в hub уходят в любом случае. Hub обновляет закреплённое сообщение не чаще, чем раз в N секунд (edit не метеринг 20/мин, но без шторма).

- [ ] статус эмодзи, контекст и лимиты цифрами из данных statusline; терминальный статуслайн пользователя не меняется
