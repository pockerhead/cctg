# TASK-029: pinned status message with an interrupt button

Type: feature
Mode: full
Priority: medium
Branch: feature/status-interrupt
Domains: hub, channel

## Description
Пользователь хочет в каждой теме закреплённое сообщение со статусом сессии (думает / выполняет инструмент / ждёт разрешения / ждёт пользователя / сессия завершена) и кнопку ⏹ «Прервать», которая останавливает текущий ход как Esc в терминале. Статус берётся из существующих сигналов (UserPromptSubmit, стрим, permission prompts, Stop, SessionEnd); сообщение одно на слот, редактируется, закрепляется один раз (служебное сообщение о закреплении удаляется, как forum_topic_edited). Прерывание: у каналов нет официальной команды; предполагаемый путь на Windows — `cctg agent` (дочерний процесс claude) делает AttachConsole к консоли своего claude и пишет Esc через WriteConsoleInputW. Сначала проба (скрытая консоль, по правилу README), подтверждающая, что Esc так останавливает ход; если нет — найти другой путь или честно отказаться. Кнопка только для allowlisted, с подтверждением от случайного нажатия.

## Acceptance criteria
- [ ] проба подтверждает механизм прерывания (или задокументирован отказ)
- [ ] закреплённое сообщение статуса одно на слот, обновляется по событиям, служебное «закрепил» удаляется
- [ ] ⏹ останавливает идущий ход живой сессии; для мёртвой/чужой сессии ничего не делает
- [ ] Existing tests pass
