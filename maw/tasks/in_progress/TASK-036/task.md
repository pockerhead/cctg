# TASK-036: team mode in one group

Type: feature
Mode: small-fix
Priority: medium
Branch: feature/team-mode
Domains: hub, channel

## Description
Решение пользователя 2026-09-24: мультиюз — это команда в одной группе, все видят всё и все allowlisted равны (для личного использования человек разворачивает свой cctg). Allowlist уже список id. Не хватает авторства:
- Входящее сообщение несёт автора: meta `from_name` (username или имя, санитизировано, без id) и префикс в content (`Имя: текст`) только когда в allowlist больше одного человека, чтобы claude видел, кто пишет. Инструкции канала говорят, что в теме может писать команда и автор указан.
- Решения по кнопкам подписываются: сообщение запроса разрешения после ответа показывает, кто нажал (`✓ Разрешено · Имя`), то же для Resume и будущих кнопок статуса (TASK-029), если они уже есть к этому моменту.
- User id по-прежнему не пишутся в логи и не уходят в сессию.
Роли и приватность не входят (все равны).

- [ ] имена санитизированы, ключи meta только `[A-Za-z0-9_]`, user id нигде не появляется
