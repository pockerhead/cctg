# TASK-059: send_file takes several files and sends them as an album

Type: feature
Mode: small-fix
Priority: medium
Branch: feature/send-album
Domains: hub

## Description
Вопрос пользователя 2026-09-26: `send_file` (TASK-032, `channel.rs`) принимает один `path` (+ `caption`). Несколько файлов = несколько вызовов и несколько сообщений, что тратит лимит группы (flood control, TASK-054).

Сделать: необязательный `paths: string[]` (2-10) рядом с `path` (ровно одно из двух). Hub отправляет их одним `sendMediaGroup`: картинки альбомом фото, остальное альбомом документов (Telegram не смешивает фото и документы в одной группе: при смешанном наборе два альбома, фото первыми); `caption` на первом элементе. Картинку, которую Telegram не принял как фото, отправить документом, как сейчас в одиночном пути. Каждый файл проходит те же проверки, что одиночный (`files.rs` read_upload, лимит 50 MB на файл, запрет device-путей). Ответ инструмента перечисляет, что ушло и что нет. Один `sendMediaGroup` расходует один токен бюджета группы.

## Acceptance criteria
- [ ] `paths` из 2-10 файлов уходит одним альбомом (фейковый Bot API: один sendMediaGroup, caption на первом)
- [ ] Смешанный набор: два альбома; один непрочитанный файл не валит остальные, об этом есть в ответе
- [ ] Старое поведение `path` не меняется; схема инструмента описывает оба варианта
- [ ] Existing tests pass
