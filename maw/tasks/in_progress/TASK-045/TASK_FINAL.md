# TASK-045: one-time join codes and per-device secrets

Type: feature
Mode: full
Priority: medium
Branch: feature/device-enrollment
Domains: hub, channel, hooks

## Description
Решение пользователя 2026-09-25 (коробочная установка, TASK-031): сейчас все клиенты знают один общий секрет hub, и строка установки клиента несёт этот главный секрет (он оседает в истории чата и shell). Нужна регистрация устройств: `/join` в General (только allowlisted) или `install.sh --hub` выдаёт одноразовый код с коротким сроком (например 10 минут, одно использование); установщик клиента обменивает код по TLS с проверкой pin на собственный секрет устройства и пишет его в `device.env`. hub хранит устройства (имя, дата, хеш секрета), принимает агентов и хуки по секрету устройства, умеет список устройств и отзыв (`/devices`, кнопка «Отозвать»); отозванное устройство отключается сразу. Старый общий секрет продолжает работать до явного отключения (миграция без поломки текущих машин).
